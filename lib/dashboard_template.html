El pipeline completo

Cinco etapas — de la recopilación de datos reales a un dashboard interactivo.

01 — EXTRACCIÓN

Datos reales, verificados

Sin dataset preexistente (el torneo terminó hace días). Cada uno de los 104 resultados se cruzó contra 8+ fuentes y se validó aritméticamente contra las 12 tablas de grupo oficiales.

Web ResearchCross-check
02 — LIMPIEZA

Transformación

Feature engineering: etapa final alcanzada por equipo, diferencia de gol acumulada, distinción entre 3er y 4to lugar.

pandasPython
03 — MODELADO SQL

Base relacional

Esquema en SQLite (equipos, partidos, goleadores). Todo el análisis exploratorio resuelto con SQL puro.

SQLiteSQL
04 — MACHINE LEARNING

Power Ranking compuesto, clustering de perfiles de equipo (KMeans + PCA), y un clasificador que valida si los datos de grupos predicen el avance.

scikit-learnKMeansRandomForest
